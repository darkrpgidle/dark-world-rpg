# 閃電鏈與雷環共鳴（2026-10-03）

## 透明影格

兩張 ImageGen 手繪 RGBA 圖集，轉 WebP 保留 alpha，各 1254×1254、4×4，共 32 格。UV 按自然尺寸除以 4（313.5px）並內縮 2px，WebGL／Canvas 2D 共用，不取整裁切或翻轉圖片。預覽角色與背景不放進正式素材。

|---|---|---|
| `public/vfx/lightning-chain/main.webp` | 0–3 | 玩家手前藍白凝聚符文 |
| 同上 | 4–7 | 水平折線電链，由程式依兩側框連接、旋轉与縮放 |

## 時間與分支

0–200ms 手前凝聚。200／350／500ms 依序接通三道藍白電鏈，每道維持最多 130ms，逐次略加粗，命中胸前出現電花。落空偏向胸前上／下方，無電花，每一道仍顯示獨立「未命中！」。

昇華只依實際已結算結果：成功原始命中逐枚留下紫色雷印。三發全命中且有「雷環共鳴」結果時，520–640ms 雷環生成、640–800ms 收束、800ms 發布独立追加結果；追加命中才播放紫白電爆与 160ms 短震（桌機 4px、手機 2px）。任一原始未命中不形成完整雷環，残印於 650ms 前淡出。追加本身未命中仍顯示第四段未命中，無電爆／震動。普通招 650ms、完整昇華 1100ms 結束。

麻痺電絲從戰鬥 session 的實際 `paralysis.expiresAt` 讀取；新麻痺在第一個成功電擊接觸後顯示，刷新不延長戰鬥定義。顯示層不新增異常判定，也不重新計時。動畫不暫停普攻／對手攻擊。

## 傷害與相容

`LiveCombatAction.lightningSegments` 暴露原本三次獨立命中／暴擊与獨立昇華結果。既有裝備追加和回放保留原結算總數，沿三原始段權重分配；雷環追加独立保留。`lightningAmounts` 只將已結算總數按實際權重分成整數，保留 overkill、零傷命中与落空的區別，不增加傷害或改變隨機判定次序。

推圖／個人首領／世界首領都由 `queueLightningNumbers` 註冊唯一逐段發布回呼。每次接觸發布 `delayMs: 0` 的共用跳字；血條与深淵王計數跟隨 `onEnemyDamageShown`，不得再次扣戰鬥 HP 或加權威分數。同次套裝／DOT 等顯示在第一成功命中發布；全落空時在第三段補齊已結算顯示。

換怪、重試與重置清除舊段；切頁／背景／回合結束補齊尚未呈現的已結算事件，登入取代直接丟棄舊段。載入失敗或 3 秒保護、無尺寸／無可用 context 均釋放全部回呼一次，避免卡血。減少動態使用靜態影格、不震動；resize 不重啟時間。新欄位僅為暫態戰鬥結果，不更動存檔／帳號／每日重置／獎勵入口。
