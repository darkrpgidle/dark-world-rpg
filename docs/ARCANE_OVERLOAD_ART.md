# 奧術超載／魔能暴走特效

## 資產

`public/vfx/arcane-overload/frames.webp`，1536×1024，保留 imagegen 原始 alpha、無損 WebP。

生成提示：透明手繪暗黑奇幻 RPG 超載魔力焰，紫白火焰沿立繪兩侧向上流動，中間透空至少45%，禁止角色、護盾圓罩、三角陣、文字、格線、煙霧與大片白閃。凝聚、啟動、普通循環、昇華電弧循環、枯竭收縮、獨立紫色符文／金紫刻痕／符文消散／碎光。火焰影格不烘焙符文，實際數量由程式獨立繪製。

生成結果的實際排版為31個來源區域，由 `overloadUv` 明確記錄，不假定所有格子相同尺寸：上方四行每行六格，下方三格枯竭與四格較窄符文。

## 角色邊框

特效 Canvas 是 `.battle-stage` 的子元素，位於角色框外，避免 `.player-frame` 的 `overflow:hidden`／clip-path 裁切魔力焰。保留角色框本身的裁切與立繪外觀。

- 角色框以即時 DOM 矩形定位，動畫尺寸為框寬2.4倍、高1.1倍，手機／桌機同一比例；補償 Canvas 與角色畫面縮放。
- 魔力焰只繪製來源左右各28%，中央44%不繪製。中央保護區寬為角色框1.056倍，左右火焰不覆蓋立繪或切過邊框。
- Canvas向左右各延伸12%、上下8%，超載／蓄能存在時允許越出戰鬥框，固定戰鬥畫面高度。
- 火焰z-index 6，護盾z-index 7，共用傷害數字仍在最上層；一般透明合成，無共用戰鬥閃白或震動。
- 三枚符文位於左右肩外與框頂附近；六道金紫刻痕位於框外兩側，各最多三道。

## 真實狀態

顯示只讀法師的 `overload`、技能蓄能與當前配置，不另算命中／施放次數、不追加傷害。

- 蓄能符文0–3枚，來自實際 `session.charge.charges.奧術超載`。
- 啟動後最多三枚強化符文，依 `remainingSuccessfulCasts` 逐次消失；未命中不減少，超載自身／追加不額外消耗。
- 昇華刻痕0–6道，依實際 `stabilityStacks`；沒有虛構穩定層數。
- 第三次有效施放後依真實 exhausted 狀態立即轉暗，持續到實際 `expiresAt`。到期只清顯示，不由渲染器修改戰鬥。
- 普通換怪沿用玩家buff與動畫相位；以戰鬥owner／配置識別切換，開始新戰鬥、卸下技能或角色切換清理。
- 接在推圖與首領的動作結算後，同時由既有100ms呈現時鐘讀取狀態；非主控期間仍更新，返回不重播過期啟動。

單Canvas WebGL，初始化／context loss時改Canvas 2D備援；圖片失敗不阻塞戰鬥。減少動態模式為靜態火焰／符文，枯竭到期清除；無持續RAF。卸載清理RAF、期限timer、ResizeObserver與圖片事件。沒有新的存檔欄位、伺服器寫入或獎勵流程。

驗證：`tests/arcane-overload-vfx.test.mjs`檢查狀態刷新、消耗、期限、手機／桌機和兩個後端的實際繪製邊界與符文數量。
