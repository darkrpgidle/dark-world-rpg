# 隕星術／天火墜星

## 資產與生成

使用內建 imagegen 生成兩套透明圖集，保留原始 alpha，以無損 WebP 轉檔。

- `public/vfx/meteor-strike/main.webp`：1536×1024，6×4、24格；實際生成圖的分段為凝聚5格、飛行7格、爆裂6格、消散6格。
- `public/vfx/meteor-strike/ascended.webp`：1536×1024，4×3、12格；收束4格、爆炸4格、消散4格。單格寬高比9:8，渲染時保留比例。

普通版生成提示：透明手繪暗黑奇幻 RPG 隕星術圖集，6列4行24格；黑色鋸齒岩石、橘紅熔岩裂紋、小面積貼線火光。符文與火核凝聚，接續同一顆隕石由右上往左下快速墜落，火尾朝右上；接觸壓縮、岩體破裂、火焰與薄橢圓衝擊環擴散，再碎石與餘燼消散。每格留邊、無角色／背景／文字／格線，避免煙霧與大片白閃。

昇華版生成提示：透明手繪天火墜星追加爆炸圖集，4列3行12格；金紅色系、熔岩碎片。四格餘燼向火核收束與符文壓縮，四格金紅火核爆裂、碎片與火射線擴散、薄衝擊環，四格散落碎光逐步淡出。固定中心、留透明邊距，無第二顆墜落隕石、無角色／背景／文字／格線，避免厚霧與大片白閃。

## 實際播放時間線

| 階段 | 影格 | 時間（開始播放後） |
|---|---|---|
| 右上召喚凝聚 | 0–4 | 0–240ms |
| 快速墜落 | 5–11 | 240–380ms，僅140ms，位移平方加速 |
| 命中炸裂 | 12–17 | 380–680ms；380ms回呼發布已結算主傷害 |
| 餘燼消散 | 18–23 | 680–1040ms |
| 昇華火核收束 | 0–3 | 460–660ms |
| 昇華追加炸裂 | 4–7 | 660–860ms；660ms發布已結算追加傷害／未命中 |
| 昇華碎光消散 | 8–11 | 860–1100ms |

凝聚起點位於怪物右上方，依敵人框即時尺寸計算；落點下移至敵框水平50%、垂直66%的中間偏下位置，主擊與昇華追加共用該落點。凝聚起點獨立於落點，維持原右上位置。火尾朝右上，按飛行方向旋轉；以核心而非整張含尾流的圖格中心定位。主爆裂以畫中接觸點對齊敵框。Canvas向上與左右擴展，僅技能存在時允許特效越出戰鬥框；玩家、敵人與場景高度不變。

## 震動與命中

- 主擊實際命中時震動整個 battle-stage，桌機最大14px、手機8px，含少量旋轉，360ms逐步收斂。
- 昇華追加實際命中時以75%強度震動260ms；追加落空只消散收束符文，不畫爆炸、不震動。
- 主擊未命中會飛過並淡出，380ms發布共用未命中提示，無命中炸裂或震動。
- 減少動態模式用靜態命中格淡出，不位移／旋轉／震動，兩筆既有結算各發布一次。
- 排除舊隕星 CSS 圖層、650ms固定震動排程與共用 impact-full，避免提前震動、重複閃白。

## 戰鬥與收尾契約

`LiveCombatAction.meteorAfterburst` 僅攜帶既有天火墜星事件的獨立命中／暴擊／倍率，不新增擲骰或改技能公式。命中原本已灼燒的目標才可能有該事件；首次新施加灼燒不憑空觸發追加。

主流程按既有已結算傷害拆分主擊與昇華，共用跳字層發布，`delayMs: 0`，兩筆合計等於原本已結算數值；不重複顯示合計。HP與深淵王本回合計數跟隨共用 `onEnemyDamageShown`，顯示層不再次扣血或加排行。

灼燒外觀等主擊回呼後才顯示，異常期限仍讀實際戰鬥狀態；元素蝕印對應火角脈衝同步改為380ms。

單Canvas WebGL／Canvas 2D備援。等圖片就緒才開始播放；圖片載入失敗／3秒逾時補齊既有傷害回呼；遲到的成功載入可恢復後續施放。主流程另以4秒上限補齊RAF停滯，切頁／隱藏時補齊，換怪／新戰鬥清除舊事件，登入取代丟棄未發回呼。全部回呼去重，不阻塞攻擊排程；卸載清理RAF、ResizeObserver、圖片事件與震動。

驗證：`tests/meteor-strike-playback.test.mjs`、`tests/meteor-strike-live.test.mjs`。

## 天火墜星重製（2026-10-04）

內建 ImageGen 生成透明 RGBA 後以無損 WebP 轉檔，保留 alpha：
- `public/vfx/meteor-strike/ascended-main-v2.webp`：1536×1024、6×4／24格；金紋召喚、赤紅熔岩星核、上右火尾、向上爆燃與餘燼。六格凝聚／六格飛行／六格主爆炸／六格淡出。
- `public/vfx/meteor-strike/ascended-v2.webp`：1536×1024、4×3／12格；金白火核收束、赤紅火花爆裂、薄金環與熔岩碎片、碎光消散。生成後再次要求縮小各格圖案至70%並增加透明邊距，避免跨格。

生成提示重點：sharp hand-painted dark fantasy, crimson vermilion fire, white-gold core, molten black shards, thin ornate gold rings, true transparent background, isolated padded cells, consistent registration; primary down-left meteor with upper-right flame tail; secondary four gathering/four ignition/four dissipating frames.

普通素材與動畫維持原樣。昇華從起手至主爆炸使用新圖集，是否使用昇華主素材直接讀實際昇華配置，不依賴灼燒追加事件。240ms開始墜落、380ms主命中、660ms既有追加命中與1040／1100ms收尾不變；昇華素材以量測火核／接觸點錨定，追加爆炸固定同一落點。WebGL與Canvas2D使用相同來源與錨點。無新增命中或傷害，落空、載入失敗、背景及減少動態沿用去重收尾。
