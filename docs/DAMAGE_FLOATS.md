# 全遊戲共用傷害跳字規格

使用者於 2026-10-01 指定：所有現有與後續更新的傷害跳字，以統一防重疊模式為基礎。適用推圖、個人首領、世界首領，三職普攻／技能／昇華／奧義／裝備追加、DOT、玩家受伤與未命中／閃避／格擋／反擊提示。

## 唯一顯示入口

- `app/combat-damage-layer.tsx`：唯一傷害數字 DOM 層，位於技能特效上方，pointer-events none。不要再新增 `damage-float`、`combo-hit`、技能專用獨立跳字層。
- `app/combat-float-events.ts`：現有 `battleHitGroups`、`setElementalHits`、`dotDamageGroups`、受傷／狀態轉成共用 `CombatFloatEvent`。新技能沿用 `battleHitGroups` 就自動接受位置分配；特殊追加可在 hit 指定 `channel: "extra"`，終極組指定 `ultimate: true, skillName`。獨立新系統可透過 `inputs.custom` 傳入穩定唯一 `id`、target、channel、已結算 damage 與 label。
- `app/combat-float-layout.ts`：共用佇列與位置分配，依目標即時 DOM 錨點、實際文字寬度與完整上浮軌跡包圍盒找空位。

## 分區與優先度

| channel | 用途 | 停留 |
|---|---|---|
| primary | 普攻、一般技能、多段每段、玩家受傷 | 700ms；暴擊 800ms |
| extra | 元素、追加箭、震地、爆破等 | 600ms，小字 |
| dot | 流血、灼燒 | 600ms，小字，偏向目標下側 |
| ultimate | 三職奧義主擊、箭雨主箭 | 1200ms，中央特大字與光環，優先占位 |
| status | 未命中、閃避、格擋、反擊成功 | 700ms |

- 一般數字優先在目標附近左右錯開，追加與 DOT 有不同的起始區域。必要時使用其他空位；不只是隨機偏移。
- 普攻、技能主傷害、追加傷害採使用者確認的「緊密上推」：最新命中固定從怪物頭部出現，已顯示數字沿同一垂直中心線向上推一行，以 70ms 過渡移動；行距 6px，不向左右找空位。各段傷害、出生時間與 600–800ms 到期时间保留，不合併、不延後命中、不重播動畫。各段共同以 22.5px/s 微飄（總距離 13.5–18px），播放至 55% 後淡出。超出頭頂可見空間時最舊段退場。奧義占住頭頂時，同一直線從其下緣進場，優先保護奧義大字。
- 冒字每格只有數字行高與上下各 1px 留白，小標保留在 title。普攻白色、暴擊橘色優先；非暴擊技能依 VFX 色系顯示（血刃紅、風箭／破星冰藍、聖箭金、昇華／奧術紫、火焰橘）。手機與桌機共用相同速度；飛出畫面自然裁切，容量不足淘汰最舊一般字。
- 手機同時最多 6 個、桌機 10 個。空間不足時最舊的一般數字提前退場，最新命中當下進場；不覆蓋正在顯示的奧義大字。連續奧義大字以新的主擊取代舊的大字。
- 非冒字分區的碰撞檢查包含完整上浮路徑、字寬及留白；頭頂冒字間採相對運動預測，確保共同存續期間不重疊，並檢查其他分區與奧義。長數字按可用寬度縮字，保留原始數字，不使用 K／M 或百分比。
- 暴擊、金色主箭、紫白昇華、冰藍狙擊、綠色元素與紅／橘 DOT 保留顏色區別；不再讓技能各自決定浮字絕對位置。
- 減少動態效果只有靜態文字淡出，無位移或放大。

疾風連射沿用同一直線上推與 6px 行距；普通箭 23px、暴擊 26px、第六箭 30px，手機／桌機一致，950ms 淡出，微飄總距離上限 18px。第一支命中箭同時發布套裝元素／共鳴追加，delayMs 明確為 0，不再套用舊 495ms 連射延遲。擊殺等該次连射 VFX 完成且呈現 HP 歸零後保留 240ms；背景／非主控仍直接收尾，6 秒上限不變。

## 時序與數值契約

敵方血條與 HP 文字必須綁定 `presentedEnemyPercent`。戰鬥原始 HP 仍由唯一結算入口計算／存檔；`CombatFloatLayout.tick` 回傳當下到期的事件，`CombatDamageLayer.onDamageShown` 在同一 RAF 更新跳字及已結算傷害的血量呈現。不得在排位器重算／再次扣戰鬥 HP。延遲 VFX 命中前保持血條，連射各段、元素、DOT、反擊均依自己的跳字事件下降；事件去重、換怪、切場及登入取代一併清理。血條不使用額外 350ms CSS 延遲。

顯示血量與實際死亡的取整規則一致：原始 HP 已歸零時，低於半點 HP 的呈現餘數（含浮點誤差）歸零。普通擊殺從死亡結算起最多等待 6 秒；若 VFX／跳字事件缺漏，強制顯示歸零並依原有防重複擊殺流程收尾，期限不隨跳字更新延長，換怪與重置取消舊收尾。

持續傷害、餘燼回響與冰碎的共用事件保留已結算傷害的小數精度，分段合計等於 actualDamage；只在文字繪製時取整。禁止先逐次四捨五入再更新呈現血量，否則多次灼燒／流血會累積少扣的餘數，最後命中仍顯示 1 HP 並等待保護期限。`combat-health-presentation.test.mjs` 重現三次 14.2 傷害後的致死主擊，確認最後跳字使呈現血量歸零。

推圖與首領的普通擊殺需等呈現血量歸零後 120ms 再進行一次既有勝利結算，避免箭未命中就換怪；箭雨仍等完整奧義收尾。已結算死亡的目標停止後續攻擊，持續使用原有擊殺防重複規則。切離主控或瀏覽器隱藏時直接收尾，返回以原始 HP 同步，不能因跳字層卸載而卡住掛機。`combat-health-presentation.ts` 僅處理呈現，不派發傷害或獎勵。

1. 戰鬥引擎先結算傷害。顯示層不得擲命中／暴擊、改 HP、派發追加攻擊或領取獎勵。
2. Sprite／WebGL 真正命中影格的回呼發布數字。新技能逐段發布時使用 `delayMs: 0`；既有同組多段排程可保留原 `delayMs`。排位器不增加等空位的延遲。
3. 每段傷害仍獨立，不合併、不重新分配已結算的數值。保留專用 VFX 的傷害權重與 overkill 分配；共用層只讀取結果。
4. 不用額外總傷害字重複多段的合計。推圖同一次受傷的 player／enemy 兩份快照只呈現一次；首領 enemy feedback 為既有外送攻擊，不再當成另一筆玩家受傷。
5. 使用來源物件身分去重，避免數字鍵重複（例如新戰鬥的 pulse 又從 1 開始）誤吞新事件。來源組合清理後，已發布的延遲段仍由共用層播放。
6. 新遠征、切地圖、開始／退出首領、登入環境取代等重置時取消舊佇列；不重播目前來源仍留著的舊快照。普通換怪保留短暫收尾數字，不重新發布。
7. Resize 重新排位但保留出生時間。動畫到期停止 RAF；卸載取消 RAF／ResizeObserver。背景分頁回來不重播過期數字。

## 新技能範例

```ts
// 呼叫自該段 VFX onImpact；damage 已由戰鬥結算，這裡只發布。
setBattleHitGroups((current) => [...current, {
  key: eventKey,
  hits: [{ damage, critical, label: "追擊", channel: "extra", delayMs: 0 }],
}]);
```

測試：`combat-float-layout.test.mjs` 驗證逐段數值／延遲、受傷去重、密集分區、奧義保護、手機／桌機邊界、縮放與重置。`combat-damage-layer-runtime.test.mjs` 使用真實 React client／StrictMode 驗證去重、延遲、戰鬥切換與 session 清理。`combat-float-contract.test.mjs` 保護唯一顯示入口與後續開發規則。

箭雨一般／昇華九支箭（含主箭）各自依實際 hit 在到達目標的回呼發布傷害或「未命中！」status。全部落空亦註冊九段回呼，不另發整招落空提示。成功命中但 overkill 分配為 0 的箭不能誤報未命中；status 不扣血。

## 世界首領傷害計數器

深淵王場內本回合傷害使用 `presentedWorldRoundDamage`，與血條共用 `onEnemyDamageShown`，各段跳字出現時累加已結算傷害（普攻、技能、昇華、DOT、套裝與反擊）。`worldRoundDamage`／`worldDamage` 維持戰鬥結算、雲端存檔與排行權威值，禁止顯示回呼再次加分。切頁、背景返回、回合結束同步權威值；新挑戰以新首領物件 token 隔離旧事件並重設計數。

霜火新星主擊以新投擲動畫 1240ms 接觸回呼發布，昇華暖色餘爆與冰碎各以自己的命中回呼發布；均沿用共用跳字層、血條與世界首領計數器。總傷害只結算一次，昇華獨立命中／暴擊仍由戰鬥層決定。切頁／背景補齊待顯示數字，換目標與重試清除旧發布。詳細時間線見 `FROSTFIRE_NOVA_ART.md`。

閃電鏈三段於 200／350／500ms 接觸，昇華雷環共鳴於 800ms 接觸，各自發布實際已結算傷害／未命中、`delayMs: 0`。原始三段與昇華追加保留獨立命中／暴擊；零傷命中不誤報落空。不額外顯示合計數字。換怪與重試清除，背景／切頁補齊，登入取代丟棄；見 `LIGHTNING_CHAIN_ART.md`。

死亡收尾現以獨立主流程監看 pending 狀態，最後跳字後的收尾時間只計一次；已讀入零血目標也受監看。跳字血量回呼在 layout effect 同步最新快照，避免繪製影格讀到上一筆 raw HP 而將最終血條卡在 1 HP。詳見 COMBAT.md 的主控換怪與同步停滯修正。

隕星術380ms主擊、天火墜星660ms追加各由真實播放回呼發布，兩筆保留獨立命中／暴擊，合計與既有結算完全相同，不追加合計字。零傷命中不誤報未命中；切頁／背景補齊、換怪／登入取代清理，RAF停滯4秒保護。見 `METEOR_STRIKE_ART.md`。

虛空崩解於720ms裂隙崩爆發布一次已結算主傷與附加數字，萬象湮滅仍同一次主傷。共用跳字同步HP與世界王計數，未命中同時回報，換怪清理／背景补齊／登入取代丟棄／4秒停滯保护，不新增浮字DOM。

星界寂滅六顆星體2040ms同時到達，各段獨立已結算數字／未命中，同一RAF發布但不合併；3000ms尾爆使用ultimate特大字，3160ms星界回爆及實際追加使用extra。保持小數與overkill合計，HP／世界王計數同跳字。沒有技能合計字。背景／切頁補齊、重試清理；完整動畫結束才進行已結算勝利並恢復攻擊。

職業神話追加由 `skill-mythic-display.ts` 按已結算實際傷害拆分，原始段與裝備段合計維持相同；泰坦裂痕、血神血爆、灼燒引爆使用既有主擊發布回呼與 `extra` channel。永恆核心破盾爆炸沿用反擊事件的同一 HP 結算／跳字入口，標記「過載爆炸」，世界王追加實際傷害一次。千羽風暴的七支原始箭與昇華追加箭沿用連射逐箭回呼，禁止額外總傷害字。
