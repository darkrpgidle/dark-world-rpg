# 戰鬥規格

## 不可破壞行為

- 攻速決定出手頻率；每次合法出手只結算一次主傷害事件。
- 多段技能可逐段顯示，但總傷害必須由單次技能結算拆分，不能因高攻速重複建立傷害。
- 面板攻擊與實際傷害必須可追溯；禁止隱藏的千倍／百分比重複套用。
- 命中、閃避、暴擊、吸血的規格上限為 100%；若程式平衡值另設軟上限，須顯示在 UI 並記入 `DECISIONS.md`。
- 勝利回滿血；死亡後 10 秒重試；技能動畫不得暫停下一次普通攻擊。
- 取消以百分比減傷作為主要模型；以攻擊、防禦與裝備差距為核心。

## 現行 balanceConfig 摘要

- 玩家成長：每級生命 +24、攻擊 +8、防禦 +5。
- 戰力：基礎 1350，每級 +56。
- 傷害倍率區間：0.55～1.8。
- 怪物威脅倍率：0.65～2.2，指數 1.75。
- 怪物傷害：基礎 3.2、樓層成長 0.24、地圖成長 0.22、最低 2。
- 越級壓制：none／light／medium／heavy／abyss 五段。

## 必測案例

- 1 等空裝三職在地圖 1：不應秒怪，也必須有死亡風險。
- 面板攻擊 78：單次普攻不可異常接近 1000，除非 combat log 能完整解釋倍率。
- 面板攻擊 680 對獄火犬：核對一次傷害、暴擊與防禦扣減。
- 換裝後下一個傷害事件立即使用新屬性，不等待下一隻怪。
- 高攻速與低攻速在相同攻擊次數下，單次傷害一致；只有時間內出手次數不同。
