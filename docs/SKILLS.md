# 三職技能規格

## 共通

- 「技能」分頁有未使用技能點時，桌面側欄與手機導覽均顯示可用點數，完全沿用「背包」數字徽章的顏色與樣式。點數依技能面板的既有等級／GM額度減去已配點數即時計算，配完即消失；不新增戰場掉落通知或額外發放點數。

- 三職所有主動技能在技能列表、已配置出戰槽與詳情顯示一句基本效果說明；未解鎖的主動技能也可閱讀。完整數值與昇華效果仍在詳情顯示。
- 戰士「鐵骨」為固定防禦加成：20／50／80／115／150；說明與目前／下級數值不加百分比符號。
- 三職奧義能量達 100 時，奧義插隊至最高施放順位；施放時暫停雙方攻擊與戰鬥計時，待該奧義動畫完成才恢復。
- 已啟用奧義時，玩家血條下方顯示 0–100 蓄能進度條與數值。

- UI 顯示破防、標記、灼燒、格擋、護盾狀態。
- 技能為低機率觸發；取消僵直系統。
- 所有持續次數以已結算攻擊計數，不以動畫格數計數。

## 戰士

- 裂地斬：10%，180% 傷害，破防 35%，持續 4 次攻擊。
- 鮮血怒吼：生命低於 40% 當下必定觸發；該局 5 次攻擊傷害 +50% 並吸血；規格上限 +60%。
- 鋼鐵壁壘：防禦依等級提高；受傷時 10% 機率完全格擋。
- 處決：每 10 次攻擊追加傷害；Lv1～5：60%／80%／100%／120%／150%。

## 遊俠

- 穿雲箭：6%，180% 傷害，忽略 35% 防禦。
- 疾風連射：新版實際規則為 5 箭，各自判定命中與暴擊；每箭 Lv1～5 為 60%／65%／70%／76%／84%。昇華「六重風葬」於五箭全命中後追加 90% 第六箭，獨立判定命中與暴擊。視覺每箭間隔 70ms、飞行 160ms，由下往上掃射，逐箭命中顯示傷害。
- 獵手本能：提高暴擊與閃避；暴擊時 10% 機率追加一次攻擊。
- 致命標記：第 6 下爆炸；Lv2 14%／160%，Lv3 18%／180%，Lv4 22%／200%，Lv5 24%／220%。

## 法師

- 霜火新星：拋物線火球於敵人處爆開，套用灼燒視覺狀態。
- 魔力護盾：護膜包裹玩家框。
- 隕星術：敵人框右上方凝聚240ms後，140ms快速砸向敵框中心；380ms炸裂與整框強震，昇華天火墜星660ms依實際追加命中呈現金紅爆炸。見 `METEOR_STRIKE_ART.md`。
- 奧術回響：原技能命中後約 0.3 秒造成第二段回響傷害；回響數字為紫／淡紫。
- 法師技能均以單體目標設計，不需要範圍傷害。

共用異常與本次法師定案規則：見 [STATUS_EFFECTS.md](STATUS_EFFECTS.md)。
