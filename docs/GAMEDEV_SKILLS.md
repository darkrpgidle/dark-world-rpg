# 暗黑世界 Codex GameDev Skills

已導入跨引擎技能：performance-optimization（卡頓/預載）、game-feel（命中/震動）、save-systems（存檔相容）、game-ui-ux（手機/HUD）、create-game-assets（影格/素材）、rpg（裝備/數值）以及 router。

使用時先讀根目錄 AGENTS.md 和 docs/PROJECT_MAP.md，按任務僅選取相關技能。

本遊戲是 React/TypeScript Web RPG，而非 Godot、Unity、Phaser；通用 Router 可能無法辨識現有引擎，直接採用對應跨引擎技能即可。第三方範例不可覆蓋原有戰鬥結算、傷害浮字、存檔相容或部署規範。所有修改先測試、禁止未授權部署。
