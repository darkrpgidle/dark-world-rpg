# GameDev Skills — 暗黑世界 Codex

這些技能是跨引擎開發參考，來源：https://github.com/gamedev-skills/awesome-gamedev-agent-skills （Apache-2.0）。

- performance-optimization：真實模式卡頓、特效預載、GC/FPS。
- game-feel：震動、連擊打擊感、動畫節奏。
- save-systems：舊存檔、版本相容、雲端同步。
- game-ui-ux：手機／背包／技能介面。
- create-game-assets：透明影格與 Sprite Sheet 資產流程。
- rpg：套裝、詞綴、經驗、數值曲線。

每次先讀 AGENTS.md 和 docs/PROJECT_MAP.md，依任務讀對應技能及 references；實際程式與專案規格優先於第三方通用範例。不可自行更換引擎、阻塞戰鬥時序、破壞現有存檔或部署正式站。先測試，再回報。
