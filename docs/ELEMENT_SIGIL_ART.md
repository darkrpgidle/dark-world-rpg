# 元素蝕印／混沌刻印

資產：`public/vfx/element-sigil/frames-v3.webp`，1536×1024、6×4、24格，保留原始透明 alpha。

內建 imagegen 全新生成提示：1536×1024、透明6列4行、24個等大方格；清晰纖細的紫色正三角線條，上角橘色火焰、左下青色冰晶、右下金色閃電；三角中央透空，不使用實心底板、白閃或大片煙霧，僅少量貼線光暈。各格置中並保留邊距，禁止角色、背景、文字與格線。0–1施放凝聚，2–5短尾流投射，6–11三角逐步刻入，12–17同方向固定幾何的持續循環，由渲染器旋轉；18–20火／冰／雷亮角，21雙三角混沌刻印，22收縮，23少量碎光消散。

| 階段 | 影格／時序 |
|---|---|
| 施放 | 0–1凝聚120ms，2–5向右飛行；300ms接觸，450ms清理尾流 |
| 附著 | 6–11，360ms；僅實際成功施加 elementSigil 才播放 |
| 持續 | 12–17，每格180ms；敵人胸前固定中心、順時針每4秒一圈，85%顯示不透明度，尺寸不超過敵框寬80%或高45% |
| 異常脈衝 | 18火／19冰／20電，320ms；僅實際 statusApplications 有成功異常才播放 |
| 混沌刻印 | 21，480ms；實際 firstAnomalyUsed 首次轉為 true 時播放一次雙三角混沌刻印 |
| 結束 | 22收縮／23細小碎光，共300ms；不爆炸、不追加傷害 |

生命週期依實際 enemy.elementSigil.expiresAt，不另算持續時間。未命中只穿過消散，不覆蓋既有印記；刷新延用實際期限、不得重複觸發已用過的昇華。異常脈衝接在霜火1240ms、閃電三擊完成500ms、隕星380ms後，其餘立即呈現。換怪清除所有舊印記／待播放脈衝；戰鬥結束、切換、重複登入均清理。

單Canvas WebGL，失效改Canvas 2D；即時读取角色與敵人框，PC／手機共用比例。主印記、元素脈衝、混沌外環與消散共用旋轉角度，刷新不重置旋轉相位；飛行保持朝右。減少動態模式使用靜態蝕印，不旋轉。圖片失敗不影響戰鬥、技能判定、Debuff 倒數及共用傷害層。移除元素蝕印共用舊特效，避免重複播放。

## 第三版重製

重新生成整套24格圖集，改用細線三角、火／冰／雷小圖案，去除上一版厚重三角底色。完整保留生成圖 alpha，以無損 WebP 轉檔；使用版本化網址，避免沿用瀏覽器舊圖快取。提高主印記顯示不透明度至85%，讓線條清楚而中央仍透出怪物；昇華首次異常改以雙三角幾何刻印呈現。

元素蝕印仍排除共用 impact-medium 的戰鬥框提亮和敵框 hit-stop；持續旋轉維持每4秒一圈。技能判定、異常加成、持續時間與戰鬥計時均維持既有流程。
