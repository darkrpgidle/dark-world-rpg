# 共用異常效果（2026-10-02）

一般技能、被動、裝備一律沿用；只有明確列出的昇華可突破。不同效果的加成各自乘算（+20% = ×1.2）；元素共振的不同種類先在該被動內相加，再與其他被動乘算。異常機率與異常效果是不同數值。

| 異常 | 基礎效果 | 可加成項目 |
|---|---|---|
| 灼燒 | 施加時攻擊力 60%／秒，五秒 | 傷害倍率 |
| 冰凍 | 無法出手三秒，重複刷新、不累加 | 時間 |
| 麻痺 | 攻速降低 30%，三秒 | 降低比例，最高 100% |
| 流血 | 每層施加時攻擊力 30%／秒，五秒，最多三層 | 傷害倍率 |
| 破防 | 比例、基礎時間由技能決定；保留較強比例並刷新 | 破防比例 |
| 枯竭 | 技能直接傷害降低 15%，五秒 | 專屬懲罰減輕比例，×(1−減輕率) |

血刃斬昇華「猩紅撕裂」可達五層，既有流血傷害 ×1.2 保留。狀態每秒在一、二、三、四、五秒各跳一次；刷新保留下一次跳傷時刻。換敵人清除敵方異常和待播放回響，禁止傷害跨目標。
