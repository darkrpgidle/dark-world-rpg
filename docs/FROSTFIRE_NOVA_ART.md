# 霜火新星投擲特效（2026-10-03）

## 素材

ImageGen 依冰火投擲分鏡重製，透明 WebP，兩張 1254×1254、4×4 圖集，共 32 格；每格來源寬高 313.5px，UV 內縮 2px 防止鄰格漏光。保留透明 alpha，正常合成，不將光暈多次加亮。玩家／敵人只取即時肖像框定位，不烘焙角色或背景。

| 圖集 | 格號（由 0 起算） | 內容 |
|---|---|---|
| `public/vfx/frostfire-nova-v2/main.webp` | 0–3 | 冰晶火球凝聚 |
| 同上 | 4–7 | 球體旋轉、短冰火尾流，路線由程式決定 |
| 同上 | 8–15 | 碰撞白芯、冰火新星、碎晶與火星消散 |
| `public/vfx/frostfire-nova-v2/states.webp` | 0–3 | 灼燒火焰，中央留空讓敵人可辨認 |
| 同上 | 4–7 | 冰殼生成並保持，中央半透明 |
| 同上 | 8–11 | 昇華暖色餘爆 |
| 同上 | 12–15 | 冰殼裂開、碎晶散落 |

完整影格、UV 與時間線由 `app/frostfire-nova-frames.ts` 定義。持續特效末段淡出由 alpha 控制，不將仍有亮光的最後影格固定留在場上。

## 施放

凝聚與球體投擲尺寸為原版兩倍；命中、持續異常、餘爆與冰碎尺寸及影格不變。

1. 0–280ms：玩家手前凝聚，短暫向後、向下收勢。
2. 280–800ms：慢拋至中央上方，800–1020ms 原地懸停，1020–1240ms 加速砸向右方，位置 `lerp(from,to,t) − 4h·t(1−t)`；尾流跟隨弧線，下降時方向向左上。弧高依角色高度與頭頂空間限制，PC／手機均由實際框定位。
3. 1240–1560ms：命中新星。`onImpact` 在碰撞影格發布已結算主傷害、同次套裝追加與待顯示 DOT；血條、深淵王計數器沿用共用跳字時序。命中輕震 140ms，桌機 2px／手機 1px。落空穿過敵人消散，只在接觸時顯示「未命中！」，不爆炸、不震動。
4. 命中後才解除新灼燒／冰凍影像的閘門。無異常時只消散；不重新擲異常機率。前一招已存在的異常可繼續，狀態時間完全依目前 session 的 `expiresAt`，不從 VFX 重新計時。

## 持續與昇華

- 灼燒四格循環（每格 130ms），到期移除；獨立每秒跳傷仍由共用戰鬥引擎結算。
- 冰凍四格生成（每格 75ms），最後一格保持到實際到期。刷新只更新期限，不重新生成、不提前冰碎。
- 昇華暖色餘爆：只在實際 `極炎霜爆` 追加判定成立時由主擊接續，四格／360ms，80ms 發布獨立傷害或未命中。追加仍使用既有獨立命中／暴擊結果，從已結算總數拆出顯示，禁止重算／重複扣血。
- 昇華冰碎：接收實際到期的 `freeze` 傷害事件，四格／400ms，100ms 發布已結算冰碎數字。換怪清除，不對下一隻怪補炸。

## 渲染與清理

`MageFrostfireNovaVfx` 以單 Canvas WebGL 2 播放主招、持續異常與昇華，Canvas 2D 備援使用同一圖集、來源矩形、時間線。技能位於肖像上方、跳字下方，依框縮放，保留角色輪廓。

圖片慢載入先等待再起算動畫；失敗或 3 秒載入保護會一次發布待顯示事件并清除演出。減少動態使用靜態影格、不震動。切頁／背景／回合結束補齐已結算顯示；換怪、首領重試、登入取代及重置清除舊影格與發布佇列。動畫不鎖住普攻，也不負責結算傷害。

生成規格：兩張純透明、無文字／格線／角色／背景的 4×4 影格圖集；暖橘紅火焰環繞冷青冰晶核心，手繪幻想風格。第一張依凝聚、旋轉球、命中新星分配 4／4／8 格；第二張依灼燒、冰殼、暖色餘爆、冰碎各分配 4 格，將拋物線與狀態期限保留給程式。

驗證：`frostfire-nova-playback.test.mjs` 檢查兩種 renderer、手機落點、載入／失敗、減少動態、未命中、刷新和圖集 alpha；`frostfire-nova-live.test.mjs` 檢查實際分支、昇華獨立判定、到期冰碎與推圖／首領的共用發布契約。
